# Vertriebs-Datenbank – Übergabe an Codex

Dieses Repository enthält einen bisherigen HTML-Prototypen (`index.html`). Für die neue Entwicklungsphase wurde der Fachumfang bewusst auf **qualitative öffentlich zugängliche Firmenkundenprofile** reduziert.

## Relevante Dateien
- [AGENTS.md](AGENTS.md): Verbindliche Regeln für Codex.
- [docs/PRODUKTANFORDERUNGEN.md](docs/PRODUKTANFORDERUNGEN.md): Fachlicher Produktumfang, Datenfelder, Datenqualität, Funktionen und Abnahme.
- [docs/CODEX_START.md](docs/CODEX_START.md): Konkreter Arbeitsauftrag für den Codex-Agenten.

## Wichtig
Die bestehende `index.html` enthält auch finanzielle/numerische KPI-Elemente. Diese gehören **nicht** zur gewünschten neuen Vertriebs-Datenbank. Der vorhandene Stand bleibt in Git erhalten; die Neuimplementierung erfolgt getrennt.

## Empfohlene Codex-Startanweisung
> Lies AGENTS.md, docs/PRODUKTANFORDERUNGEN.md und docs/CODEX_START.md vollständig. Prüfe das bestehende Repository, setze den MVP in dieser Branch tatsächlich um und dokumentiere Tests, Startanleitung und offene Punkte. Halte die inhaltlichen Ausschlüsse strikt ein.
